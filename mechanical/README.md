# Mechanical

Design files for the AstroLife housing, by Ben Vo. The housing holds the
ESP32, the MAX30102 sensor and their wiring in one unit.

This folder is a placeholder. Nothing has been added yet.

## What goes here

| Kind of file | Examples |
|---|---|
| CAD source files | `.f3d`, `.step`, `.sldprt` |
| Printable or manufacturable files | `.stl`, `.3mf`, `.dxf` |
| Drawings and dimensions | `.pdf`, `.png` |
| Photos of the built housing | `.jpg`, `.png` |
| Assembly notes | A short `ASSEMBLY.md` |

When files are added, replace this section with a short description of the
housing: material, how it was made, and how the parts fit together.

Wiring and firmware are in [../electrical/](../electrical/) and
[../docs/HARDWARE.md](../docs/HARDWARE.md).
